# MirrorAI Research Project

This repository houses the research and development work for **MirrorAI**, an AI companion designed to support mental health using advanced Large Language Models (LLMs). The project explores innovative ways to provide empathetic, therapeutic, and personalized mental health support through AI-driven conversations.

## Key Features
- **AI-driven Conversations**:
  - Utilizes state-of-the-art LLMs to simulate meaningful and empathetic interactions.
  - Focused on improving accessibility to mental health support.

- **Research-Oriented Development**:
  - Investigates the psychological and behavioral impacts of AI companions.
  - Incorporates data-driven insights to refine AI behavior and response quality.

- **Multi-Disciplinary Approach**:
  - Combines expertise in AI, psychology, and user experience to create a holistic support tool.

## Repository Structure
- **`Notebooks/`**: Includes Jupyter Notebooks for research experiments and data analysis.
- **`src/`**: Contains source code for MirrorAI's core functionalities, written in Dart and Python.
- **`data/`**: Datasets used for training and evaluation.
- **`docs/`**: Documentation and research findings.
